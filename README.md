# 별로 전하는 감사 · Stars for Life's Good

고객의 감사와 칭찬을 밤하늘의 별로 표현하는 인터랙티브 웹 성도(星圖)입니다.
검은 화면 가득 **1만 개의 별**이 각자 조금씩 밝아졌다 어두워지며 반짝이고,
그 사이에 **7개의 별자리**가 감사·칭찬의 메시지를 품습니다.

## 주요 기능

- ⭐ **1만 개의 반짝이는 별** — three.js `Points` + GPU 셰이더로 단일 draw call, 부드러운 60fps
- ✨ **7개의 감사 별자리** — 마음(♥), 빛나는 당신(★), 함께 성장(🌱), 손잡음, 최고(👑), 믿음(날개), 변치 않는 마음(∞)
- 💬 **메시지 발견** — 황금빛 '특별한 별'이나 별자리를 클릭하면 실제 고객 감사글이 카드로 표시
- 🎛️ **토글** — 별자리 · 반짝임 · 라벨 On/Off, 뷰 리셋
- 🔍 **탐색** — 마우스 휠/핀치로 줌, 드래그로 팬, 별자리 클릭 시 부드럽게 포커스

## 실행

번들러 없이 정적 파일만으로 동작합니다. 정적 서버로 열어주세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

> `file://`로 직접 열면 ES 모듈/`fetch`가 막히므로 반드시 로컬 서버로 실행하세요.

## 구조

```
index.html                 진입점 (import map으로 three.js 로드)
styles.css                 UI 스타일 (검은 배경, 컨트롤 바, 메시지 카드)
src/
  main.js                  씬·렌더러·애니메이션 루프 오케스트레이션
  starfield.js             1만 개 배경 별 + 반짝임 셰이더
  constellations.js        7개 별자리(노드·선·라벨) 생성
  controls.js              직교 카메라 줌/팬/포커스 컨트롤
  picking.js               특별한 별 생성 + 클릭/호버 픽킹
  ui.js                    토글 버튼·메시지 카드·조작 안내
data/
  constellations.json      7개 별자리 정의(좌표·연결선·문구·메시지)
  stars.json               메시지를 가진 특별한 별(고객 감사글)
vendor/
  three.module.js          three.js r160 (로컬 벤더링, 오프라인 동작)
```

## 감사 메시지 추가

코드 수정 없이 `data/stars.json`의 `featured` 배열에 항목을 추가하면 됩니다.

```json
{ "x": 300, "y": -200, "name": "홍길동 고객님", "message": "감사합니다!" }
```

`x`, `y`는 성도 좌표(대략 ±1600 범위)이며, 별자리 대표 문구·메시지는
`data/constellations.json`에서 편집합니다.
